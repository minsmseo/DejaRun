# DejaRun

**Find the experiment you are about to repeat, before you run it.**

DejaRun is an Atlassian Forge app for R&D labs. When a researcher plans a new experiment in Jira, DejaRun looks for past experiments with the same conditions in Jira and Confluence and shows them with their results.

Built for Atlassian Codegeist 2026, category **Apps for Specialized Industries**.

> Work in progress. The app currently deploys a placeholder Jira issue panel. All demo data will be fictional.
